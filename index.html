가격 추이 (부가세포함)

재고관리 프로그램에서 뽑은 원본 CSV/엑셀을 올리면 분기 보고서용 표·그래프를 만들어줍니다. 파일은 서버로 업로드되지 않고 이 브라우저 안에서만 처리됩니다.

1서버 입출고

컬럼: 제품명 / 입고수량 / 출고수량 (규격, LEVEL은 있으면 활용, 없어도 동작)

CSV 또는 엑셀(xlsx) 파일을 여기로 끌어놓거나 클릭해서 선택하세요
CSV에 LEVEL 컬럼을 직접 지정하면 이 목록 대신 그 값을 우선 사용합니다.
📦 누적 히스토리 & 기간별 조회
히스토리 0건
~
각 행에 날짜 컬럼이 없으면 "히스토리에 추가"한 날(오늘)로 기록됩니다. 다음 분기에도 이 파일(히스토리 JSON)을 불러온 뒤 새 데이터를 추가하면 계속 누적됩니다.

2보안장비 출고

컬럼: 모델명 / 수량 (날짜, 업체명은 있으면 활용, 없어도 동작)

CSV 또는 엑셀(xlsx) 파일을 여기로 끌어놓거나 클릭해서 선택하세요
📦 누적 히스토리 & 기간별 조회
히스토리 0건
~
각 행에 날짜 컬럼이 없으면 "히스토리에 추가"한 날(오늘)로 기록됩니다. 다음 분기에도 이 파일(히스토리 JSON)을 불러온 뒤 새 데이터를 추가하면 계속 누적됩니다.
💡 각 그래프 우측 상단의 "PNG 저장" 버튼을 누르면 이미지 파일로 바로 다운로드됩니다. PPT에 끌어다 놓기만 하면 돼요.
💡 컬럼 이름이 CSV마다 달라도 괜찮습니다 — 업로드 후 드롭다운에서 어떤 컬럼이 무엇인지 직접 지정하면 됩니다.
💡 데이터를 계속 쌓아가려면: ① 표·그래프 생성 → ② "히스토리에 추가" → ③ "히스토리 JSON 저장"으로 파일 보관. 다음에 작업할 땐 그 JSON을 "히스토리 불러오기"로 연 다음 새 데이터를 다시 추가하면 계속 누적됩니다. 이 도구는 서버에 아무것도 저장하지 않으므로, 히스토리 JSON 파일을 직접 보관하셔야 합니다.
